## 玩法

发射小圆去撞漂浮的大圆：碰到就粘成一只耳朵；两只耳朵正对着贴好，头就完成了。

把完整的头送到经过的身体旁，它会自动接上。别让场上的东西撞到身体——掉光血就是炸单；没接到头的身体算空车。连续炸单太多，本局结束。

时间越久、场上越热闹，来车会越来越频繁。送达率越高，评价越好。

## 操作

| 操作        | 方法                     |
| ----------- | ------------------------ |
| 鼠标 / 触屏 | 移动瞄准，点击或轻点发射 |
| 键盘        | `空格` 发射，`ESC` 暂停  |

## 设置

- **不败模式**：永远不会失败，放心练手
- **严格模式**：接到头后身体仍会受击，每 3 次受击掉 1 血
- **飙速模式**：来车频率随时间和场上压力加快，最高形成紧挨的车队

## 技术

纯静态网页，无依赖、无构建，克隆或下载后直接用浏览器打开即可游玩，也适合部署到任意静态托管。
